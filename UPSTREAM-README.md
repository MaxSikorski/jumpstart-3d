# JumpStart 3D v2.9.8.1: complete source code

Everything needed to rebuild JumpStart 3D v2.9.8.1 (with the Mac / iPad / iPhone work, the open-source credits, and 60 step-by-step tutorials (Beginner, Advanced, Expert and Architect; two of them for the Lathe) with built-in animations) is here: the app's own code, every third-party library and font that goes into it, the geometry engine, the build scripts and the test scripts.

New in v2.9.8.1: Box Maker doors get a catch (`doorCatch`: none, light or firm in `app/src/bins.js`): two small round bumps on the case's far wall, just in front of the shut door's free edge, reaching past it by 0.35 or 0.7 so the door clicks shut and needs a small pull to open. Fixed: `caseParts` now cuts the case's hollow and holes first and adds the things inside it (door stop strips, catch bumps) after, so the hollow no longer cuts them away. Tests: `tests/tdoorcatch.cjs`, `tests/tsa2981.cjs`.

From v2.9.8: Box Maker grids (`app/src/bins.js`): `across` sets how many side by side as well as `units` high; `sideJoints` adds dovetail rails (or pegs) on each box's right side and the matching closed-front grooves (or holes) in its left side, with the side walls (or an open bin's walls) made thick enough for them; parts are keyed down each column then across, so sets made before keep their parts, and named by grid place (A1, B2…). Doors get a stop strip just behind them along the case floor, ceiling and far side, so they open outwards only. Tests: `tests/tbingrid.cjs`, `tests/tsa298.cjs`.

From v2.9.7.1: Box Maker doors (`caseParts` in `app/src/bins.js`) get a pull choice (`doorPull`: knob, finger hole or bar) on the front only, and a flat back: the door is 3.2 thick, its hinge edge and pins are no thicker than it, and the knob's stem stops inside the door. Laid out to print, `binSet` turns each door onto its back (pull up). Tests: `tests/tdoorpull.cjs`, `tests/tsa2971.cjs`.

From v2.9.7: Box Maker fixes in `app/src/advanced.js` (`binCmd`): placing ignores every body of the set (`placeOn` takes a test of ids), so the set can't land on its own parts; typing waits for a pause before rebuilding, and redraws keep keyboard focus; each build works out which parts to remove from the parts the document has, so a smaller set really loses its extra bodies (the preview used to change the shared list). In `app/src/beginner.js` a click picks the whole set (`setOf`), the side panel shows the set with Edit in Box Maker, and a double-click opens it. Tests: `tests/tbinglitch.cjs`, `tests/tbinuse.cjs`, `tests/tsa297.cjs`.

## Building

You need Python 3, Node.js 18 or newer, `gzip`, and a Bash shell (macOS, Linux, or Windows with WSL / Git Bash).

```bash
cd app
bash dist.sh          # builds dist/ (index.html, app.js, worker.js, occt-gz.wasm)
python3 standalone.py # makes jumpstart-3d.html: the whole app in one file
```

The build finds the libraries in `third_party/` next to `app/`, so keep the two folders side by side. It uses an `esbuild` on your PATH if there is one, otherwise esbuild 0.28.2 through `npx` (downloaded on first use). To use a particular esbuild:

```bash
ESBUILD=/path/to/esbuild bash dist.sh
```

To try it, open `app/jumpstart-3d.html` in a browser, or serve `app/dist/` with any web server (`python3 -m http.server` inside `app/dist`) and open `index.html`.

The build steps, in order:

1. Compress the geometry engine (`third_party/replicad-opencascadejs/dist/replicad_single.wasm`) into `dist/occt-gz.wasm`.
2. Bundle three.js for the embedded tools, then build FlexiGen, Mesh to STEP and Chisel from `tools/` into `src/flexigen.html`, `src/meshstep.html` and `src/chisel.html`.
3. Bundle `src/app.js` (the app) and `src/worker.js` (the geometry engine's worker).
4. `standalone.py` puts the page, the app, the worker and the engine into one HTML file.

## The geometry engine (LGPL)

The CAD engine is Open CASCADE Technology, compiled to WebAssembly by the opencascade.js project, in the custom build that replicad publishes as `replicad-opencascadejs`. It is licensed under the GNU Lesser General Public License 2.1 (`LICENSES/LGPL-2.1-opencascade.txt`).

The engine stays a separate file: `dist/occt-gz.wasm` in the web version, and its own block (`<script id="wp-occt">`) inside the single-file version. To use a different or modified build of the engine, replace `third_party/replicad-opencascadejs/dist/replicad_single.wasm` and `replicad_single.js` with your build and run the build again.

Source code for the engine:

- Open CASCADE Technology: https://github.com/Open-Cascade-SAS/OCCT
- opencascade.js (the WebAssembly build system): https://github.com/donalffons/opencascade.js
- The replicad build configuration: https://github.com/sgenoud/replicad/tree/main/packages/replicad-opencascadejs

# JumpStart 3D v2.8.1.3: complete source code

Everything needed to rebuild JumpStart 3D v2.8.1.3 (with the Mac / iPad / iPhone work, the open-source credits, and 38 step-by-step tutorials (two of them for the Lathe) with built-in animations) is here: the app's own code, every third-party library and font that goes into it, the geometry engine, the build scripts and the test scripts.

New in v2.8.1.3: the 3D Print Sim can **arrange the plate like Orca Slicer** (`app/src/printsim.js`): each body on the plate is an object with its own sim-only placement (`st.inst`: `X`, scale, copy number), so objects can be picked (click, Shift-click or the Objects list), dragged on the plate, turned by any angle around X, Y or Z, laid on a face, scaled, duplicated into free spots (`freeSpot`, `dupObj`), arranged in rows (`arrange`) and reset. `buildWorld` slices every object, copies included (copies are drawn by the sim, `buildCopies`); the bodies in the design are never changed. The Advanced Design ribbon has a Workshop group at the right end (Fasteners, Chip Carving, Lathe); Stained Glass stays on the Simulate tab. Test: `tests/tps.cjs` (turn, scale, copy, arrange, drag, lay flat, remove, reset, then checks the design is unchanged).

Also new in v2.8.1.3: the Floor Planner has its own **step-by-step tutorials** (ten projects in `app/tools/fp_tutorials.js`, run by the guide panel and chooser in `app/tools/fp_addons.js`, styled like JumpStart 3D's; both are built into `app/src/floorplan.html` by `app/tools/make_floorplan.py`), so they work inside the planner and in its own tab; the JumpStart 3D tutorials button and the Floor Planner tab in JumpStart 3D's Tutorials are gone. **Quick save** (`fp_addons.js`): 💾 Save / Ctrl+S with a Last name, First name, Plan name, 📂 My plans (open, copy, delete, save to a file, open a file, new plan), and an autosave of the last plan with Continue / Start fresh. Tests: `tests/tfp3.cjs` (a tutorial done through the real buttons, Ctrl+S, saving a file) and `tests/tfp4.cjs` (continue the last plan, My plans).

From v2.8.1.2: the **Floor Planner** in Architect (`app/src/floorplan.js` opens it in its own window over the app and keeps it running while hidden; `app/src/floorplan.html` is made by `app/tools/make_floorplan.py` from `app/tools/floorplanner-source.html`, the Blueprint Floorplanner, with three.js r128 from `third_party/three-r128` built in, the classroom check marked as play money, saving through JumpStart 3D, a Back to Architect button and a `__fp` bridge the tutorials read). **Floor Planner tutorials** (moved into the planner in v2.8.1.3). Tests: `tests/tfp.cjs` (open, draw, download, 3D, a tutorial ticking off) and `tests/tfp2.cjs` (every tutorial step can be completed).

From v2.8.1.1: **print times like Orca Slicer** (`app/src/motion.js`: `MOTION`, the feature speeds and accelerations of Orca Slicer's bundled 0.20 mm profiles per printer family; `timeMoves`, a port of Orca's G-code time estimator, with Marlin classic jerk junctions, the Bambu centripetal limit or Klipper junction deviation, and reverse / forward planning into trapezoids; `COOLING`, slow-down for layer cooling). `makeGcode` in `app/src/gcode.js` builds each layer's moves, times them, slows short layers, then writes them with per-feature `M204` and without retractions between infill lines; `planTime` in `app/src/printsim.js` uses the same estimate for the sim and rescales the print animation to it; top and bottom skins are spaced one line width apart. **42 more Text-tool fonts** (`app/src/fonts_more.js`, made by `app/tools/make_fonts.py` from `app/tools/fontlist.txt` and a Google Fonts checkout: subsets without hinting, renamed "JumpStart <style>"; TTFs in `app/fontsub/more`, licences in `LICENSES/fonts-more.txt`). The worker gets them as assets (`registerFont` in `app/src/fonts.js`, `setAsset` kind "font" and `fontsReady` in `app/src/kernel.js`), and font pickers are grouped (`fontSelect`). **Quick Hinge** (`app/src/hinges.js`: print-in-place, pin and living hinges from primitives; `hingeCmd` in `app/src/advanced.js`). **Architect** opens in feet and inches (its own unit, restored on leaving) with a length / angle and width / depth entry box while drawing (`typeBox*`, `typedLen` in `app/src/arch.js`). Beginner's toolbar: CosForge, Chip Carve and Lathe moved to the right. `standalone.py` stores the app and worker gzipped and unpacks them in the page (DecompressionStream). Tests: `tests/ttime.cjs`, `tests/thinge.cjs`, `tests/tarch.cjs`, `tests/tfont2.cjs`, and `node tests/motion.mjs` (planner checks).

## Building

You need Python 3, Node.js 18 or newer, `gzip`, and a Bash shell (macOS, Linux, or Windows with WSL / Git Bash).

```bash
cd app
bash dist.sh          # builds dist/ (index.html, app.js, worker.js, occt-gz.wasm)
python3 standalone.py # makes jumpstart-3d.html: the whole app in one file
```

The build finds the libraries in `third_party/` next to `app/`, so keep the two folders side by side. It uses an `esbuild` on your PATH if there is one, otherwise esbuild 0.28.2 through `npx` (downloaded on first use). To use a particular esbuild:

```bash
ESBUILD=/path/to/esbuild bash dist.sh
```

To try it, open `app/jumpstart-3d.html` in a browser, or serve `app/dist/` with any web server (`python3 -m http.server` inside `app/dist`) and open `index.html`.

The build steps, in order:

1. Compress the geometry engine (`third_party/replicad-opencascadejs/dist/replicad_single.wasm`) into `dist/occt-gz.wasm`.
2. Bundle three.js for the embedded tools, then build FlexiGen, Mesh to STEP and Chisel from `tools/` into `src/flexigen.html`, `src/meshstep.html` and `src/chisel.html`.
3. Bundle `src/app.js` (the app) and `src/worker.js` (the geometry engine's worker).
4. `standalone.py` puts the page, the app, the worker and the engine into one HTML file.

## The geometry engine (LGPL)

The CAD engine is Open CASCADE Technology, compiled to WebAssembly by the opencascade.js project, in the custom build that replicad publishes as `replicad-opencascadejs`. It is licensed under the GNU Lesser General Public License 2.1 (`LICENSES/LGPL-2.1-opencascade.txt`).

The engine stays a separate file: `dist/occt-gz.wasm` in the web version, and its own block (`<script id="wp-occt">`) inside the single-file version. To use a different or modified build of the engine, replace `third_party/replicad-opencascadejs/dist/replicad_single.wasm` and `replicad_single.js` with your build and run the build again.

Source code for the engine:

- Open CASCADE Technology: https://github.com/Open-Cascade-SAS/OCCT
- opencascade.js (the WebAssembly build system): https://github.com/donalffons/opencascade.js
- The replicad build configuration: https://github.com/sgenoud/replicad/tree/main/packages/replicad-opencascadejs

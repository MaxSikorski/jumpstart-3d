# JumpStart 3D

A browser-based 3D CAD tool (a Tinkercad-style alternative) that runs entirely from a single HTML file. No install, no server, no account.

**Use it here:** https://maxsikorski.github.io/jumpstart-3d/

Or download `jumpstart_3d_v1.91.html` and open it in any modern browser. It works offline apart from the Google Fonts it loads for its UI.
